## Reproducing Locally

```bash
VT_MOCK_AI=1 npm run build
VT_MOCK_AI=1 npm run start
node vt-e2e.cjs
# If another app owns port 3000:
VT_BASE_URL=http://localhost:3001 node vt-e2e.cjs
```

Captured QA screenshots are written to `docs/test-shots/`. The README tour
uses the curated `docs/screenshots/` set generated by `vt-fp-shots.cjs`.
